# OEL Companion for AniList

Unofficial browser extension that adds a personal OEL / manhwa / manhua
library and custom activity entries to AniList, sourced from MangaDex.

**100% local.** Nothing is sent to AniList's servers and your real AniList
account, lists, and data are never read, written, or modified.

## Features

- Search MangaDex for OEL / manhwa / manhua titles
- Track status (Reading / Planning / Completed / Paused / Dropped)
- Track chapters with +/− stepper (editable by keyboard)
- Injects realistic "Read chapter X of Y" entries into your feed
- Click a feed entry's poster or title to edit it in place
- Auto-fetches missing covers (MangaDex → Comick → MangaBaka)

## Install

1. Download the latest `oel-companion.zip` from Releases
2. Unzip it to a folder
3. Open `chrome://extensions`
4. Enable **Developer mode** (top right)
5. Click **Load unpacked** and select the folder
6. Open `anilist.co` — the OEL Library card appears at the top of your feed

## Privacy

- Your library is stored in your browser's local storage only
- The extension never calls the AniList API and never touches your account
- Data is never sent anywhere except MangaDex/Comick/MangaBaka lookups you trigger
